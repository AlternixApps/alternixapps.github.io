Privacidade do site

Ao visitar o site

Você pode navegar sem cadastro. Não usamos cookies, rastreadores de publicidade nem ferramentas de análise. Se você mudar o tema, o navegador guarda sua escolha.

Alojamento

Este site está hospedado no GitHub Pages. O GitHub registra os endereços IP dos visitantes por motivos de segurança.

Políticas dos produtos

Cada aplicação Alternix tem a sua própria política de privacidade, com detalhes sobre funções, permissões, SDK e tratamento de dados.

E-mail
