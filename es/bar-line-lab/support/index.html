BAR Line Lab · Soporte

¿Cómo podemos ayudarte?

Respuestas claras sobre la creación, el escaneo, la edición y la exportación de códigos de barras lineales. Esta página no contiene formularios ni recoge el texto de tus consultas.

Sitio del desarrollador

Crear un código de barras

Elige uno de los nueve estándares, introduce el valor y pulsa «Crear». BAR Line Lab comprueba la longitud, los caracteres permitidos y el dígito de control antes de dibujar el código.

Escanear con la cámara

Abre el escáner desde la pantalla principal, permite el acceso a la cámara y coloca todo el código dentro del marco. El reconocimiento se realiza en el dispositivo. Una luz uniforme y una cámara estable mejoran el resultado.

Editar y verificar

El editor permite cambiar los colores, el fondo, la altura de las barras, los márgenes y la numeración visible. La verificación analiza la estructura y estima el contraste en una escala de cinco puntos; es una comprobación práctica, no una certificación de laboratorio.

Exportar y compartir

JPEG se puede exportar sin ver publicidad. PNG, SVG, PDF, EPS y TIFF quedan disponibles después de un anuncio con recompensa voluntario. Si no hay ningún anuncio disponible, inténtalo más tarde o usa JPEG. SVG, PDF y EPS conservan la geometría vectorial; Android controla dónde se guarda el archivo y qué aplicación lo recibe.

Qué incluir en una consulta

Indica el modelo del teléfono, las versiones de Android y BAR Line Lab, el estándar del código y una breve descripción del problema. Una captura ayuda, pero elimina antes cualquier valor confidencial.
