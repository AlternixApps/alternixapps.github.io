Privacidad del sitio

Cuando visitas el sitio

Puedes navegar sin registrarte. No usamos cookies, rastreadores publicitarios ni herramientas de análisis. Si cambias el tema, tu navegador guarda la elección.

Alojamiento

Este sitio se aloja en GitHub Pages. GitHub registra las direcciones IP de los visitantes por motivos de seguridad.

Políticas de los productos

Cada aplicación de Alternix cuenta con su propia política de privacidad, donde se describen sus funciones, permisos, SDK y tratamiento de datos.

Correo electrónico

Si nos escribes, recibimos la dirección, el mensaje y los archivos que decidas enviar. Los usamos únicamente para responder, investigar el problema y conservar el historial de soporte necesario.
