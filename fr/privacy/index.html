Confidentialité du site Alternix

Cette page explique simplement ce que fait le site Alternix — et surtout ce qu’il ne fait pas.

Un site statique

Le site Alternix ne demande aucun compte et n’utilise ni formulaire, ni publicité, ni outil d’analyse, ni pixel de suivi, ni police externe, ni bibliothèque JavaScript tierce.

Choix du thème

Lorsque vous changez de thème, seul ce choix est conservé dans le stockage local de votre navigateur. Alternix ne le reçoit pas.

Hébergement

Le site est hébergé par GitHub Pages. GitHub peut traiter les données habituelles d’une requête, comme l’adresse IP et les informations du navigateur, afin de fournir et sécuriser le site selon sa propre politique.

Politiques des produits

Chaque application Alternix dispose de sa propre politique de confidentialité décrivant ses fonctions, autorisations, SDK et pratiques liées aux données.

E-mail

Si vous nous écrivez, nous recevons l’adresse, le message et les pièces jointes que vous choisissez d’envoyer. Nous les utilisons uniquement pour répondre, examiner un problème et conserver les éléments de support nécessaires.
