Prywatność na stronie Alternix

Krótko wyjaśniamy, co robi strona Alternix i — co równie ważne — czego nie robi.

Statyczna strona

Strona Alternix nie wymaga konta i nie zawiera formularzy, reklam, analityki, pikseli śledzących, zewnętrznych fontów ani bibliotek JavaScript innych firm.

Ustawienie motywu

Po zmianie motywu strona zapisuje wyłącznie ten wybór w lokalnej pamięci przeglądarki. Alternix go nie otrzymuje.

Hosting

Strona jest hostowana przez GitHub Pages. GitHub może przetwarzać standardowe dane żądania, takie jak adres IP i informacje o przeglądarce, aby dostarczać i zabezpieczać witrynę zgodnie z własną polityką.

Polityki produktów

Każda aplikacja Alternix ma własną politykę prywatności opisującą funkcje, uprawnienia, SDK i sposób przetwarzania danych.

E-mail

Jeśli do nas napiszesz, otrzymamy adres, wiadomość i załączniki, które zdecydujesz się wysłać. Użyjemy ich wyłącznie do odpowiedzi, sprawdzenia problemu i przechowania niezbędnej historii pomocy.
